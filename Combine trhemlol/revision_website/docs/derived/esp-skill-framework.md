# Employer Set Project skill framework

        Assessment footprint:
        - Duration: 870 minutes
        - Marks: 100
        - Weighting: 40% of core, 20% of qualification

        Task model:
        - Planning a project: Project planning tools, Gantt chart, resource and cost plan, rationale.
                - Task sequencing and milestone planning
- Resource allocation and cost calculation
- Decision rationale with risks, benefits, time, and cost impact
- Identifying and fixing defects in existing code: Testing, defect diagnosis, remediation, and evidence capture.
                - Test selection and test data
- Expected versus actual results
- Corrective actions and refinement
- Designing a solution: Decomposition, algorithms, conventions, and communication of design intent.
                - Breakdown of the problem into computational parts
- Appropriate notation including flowcharts or code
- Audience-aware design communication
- Developing a solution: Code organisation, technical skill, user experience, and implementation quality.
                - Readable, modular, convention-led code
- Appropriate handling of data, security, and exceptions
- Evidence that the solution meets the brief
- Reflective evaluation: Review how well the product meets requirements and user needs.
                - Success criteria review
- Testing-informed evaluation
- Improvements if the problem were revisited

        Assessment objectives:
        - AO1: Planning (12%)
- AO2: Application (41%)
- AO3: Selecting relevant techniques and resources (9%)
- AO4: English, maths, and digital communication skills (3%)
- AO5a: Project outcome (26%)
- AO5b: Review (9%)
